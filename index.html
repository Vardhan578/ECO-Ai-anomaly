⚙️ Anomaly Detection Engine Configuration

EcoPulse evaluates every water-flow reading against zone-specific baselines, duration heuristics, and hydraulic pressure differentials.

Detection Sensitivity: Engine: Active
Rule 1: Sudden Pressure Drop Critical
Triggers when hydraulic pressure drops by ≥ 0.75 bar while flow rate is non-zero (≥ 0.4 L/min). Detects catastrophic line shear.
Rule 2: Catastrophic Flow Burst Critical
Triggers when flow exceeds the zone burst rating (Kitchen: 18 L/m, Bathroom: 16 L/m, Garden: 22 L/m, Main: 35 L/m).
Rule 3: Inactive Zone Unscheduled Flow Warning / Critical
Flags continuous flow (>15s) occurring outside scheduled operational hours (e.g. Garden irrigation outside 17:00-19:00 window).
Rule 4: Continuous Low-Flow Trickle Warning
Flags low-rate continuous flow (0.4 – baseline max) persisting uninterrupted beyond duration threshold (Bathroom: 35s, Kitchen: 45s).
Rule 5: Normal High Usage Accommodation Normal
Elevated flows within permissible durations (filling pasta pot <30s, short shower <45s) remain classified as Normal to avoid false positives.
